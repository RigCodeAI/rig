# Rig

Catch security problems while your agent codes.

Rig gives your coding agent security checks tailored to your project, so it can catch and fix problems as it works. It works with Claude Code and Codex.

## Get Rig

- [Downloads](https://downloads.rig.ai)
- [Rig website](https://rig.ai)

## Bugs and feature requests

[Report a bug or suggest a feature](https://github.com/RigCodeAI/rig/issues/new/choose).

Before opening an issue, search existing issues to see whether someone has already reported it. Remove private code, secrets, and personal information from anything you share.
